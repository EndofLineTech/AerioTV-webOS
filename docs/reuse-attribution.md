## Release artifact checklist for E03/E12

1. Before first copied code/asset lands, select and add the webOS repo's license and COPYRIGHT/NOTICE material consistent with actual authorship and upstream GPL; preserve original headers. Do not assert that a license file already exists here.
2. Keep a provenance manifest (upstream commit/path, destination path, license, modification note) for code and bundled artwork. Use the owner's brand permission for AerioTV marks; retain attribution for external TMDB and third-party marks.
3. Include applicable license texts and credits in **Settings → About → Open Source Licenses** and with release artifacts. Audit runtime dependencies from the actual lockfile/package and packaged IPK, not the mobile READMEs.
4. Offer complete corresponding source for the distributed version, including build scripts, interfaces and any modified covered libraries as applicable. Verify sideload/IPK and LG Store terms against GPL distribution requirements before release; do not assume Store policy compatibility without checking.
5. Avoid copying secrets, upstream signing profiles, API keys, provider credentials, user-provided media, screenshots of private servers, or unneeded proprietary SDK binaries into this public repository.

References are descriptive implementation requirements, not a legal opinion; E01 documents provenance and release handoff, while E12 verifies the actual shipped bill of materials.
