Reference snapshot: Apple [`adad9b0`](https://github.com/jonzey231/AerioTV/tree/adad9b0ca082833abed1b56509474aaecf1cb0f7) (A), Android [`de9389f`](https://github.com/jonzey231/AerioTV-Android/tree/de9389f2661d3e2b142c10f5b9595213468c1bfb) (D). No live-user recordings or device capture were provided; see [visual baseline](visual-baseline.md).

## Baseline rule

Use tvOS runtime routes and labels first. Android TV adds complementary functionality only after explicit gating in [platform decisions](platform-decisions.md). A README description, an old design plan and a commented-out row cannot override code that builds the current TV view. In particular: `Design/Typography.swift:500-518` disables the tvOS Live TV List; `Features/Home/HomeView.swift:4410-4454,6793-6804` defines **Live TV, DVR, Movies, TV Shows, Settings**, with Favorites implemented as a group, not a tab. On TV, show DVR only when applicable and Movies/TV Shows only when that library is available; maintain selected-tab stability across provider refresh (`HomeView.swift:6855-6888`). Android TV at this snapshot retains an **On Demand** tab rather than split Movies/TV Shows (`feature/main/MainScaffold.kt:2986-3006`).

S09 and multiview-related controls below remain **upstream references for the
deferred E10 phase**, not requirements to render them in the current app.

## Cross-feature conditional rules

1. Dispatcharr: server-side recordings, permissions, XMLTV override, User-Agent, stream-source switching for eligible admin and server VOD; Xtream: provider catalog/EPG and optional XMLTV; M3U: live-only and optional EPG URL. Source-specific fields are in `EditServerPage.swift:269-443` and server permissions `ServerDetailView.swift:820-885`.
2. Live guide cells remain selectable without EPG; favorites/collections are guide groups. Default group is pinned by holding group token (`ChannelListView.swift:23-64`). Group reordering/visibility is via `Design/Components/ManageGroupsSheet.swift`.
3. VOD Watchlist, Hide/Unhide, Continue Watching, category/provider/sort/search and detail routes are in `Features/VOD/MoviesView.swift`, `TVShowsView.swift`, `VODDetailView.swift`. Photos/cast/episode metadata vary by provider. DVR state/record action gates in `Features/DVR/DVRView.swift` and `Features/LiveTV/RecordProgramSheet.swift`.
4. Player options/tile menus are enumerated above based on **rendered** SwiftUI body branches; comments/READMEs lag recent changes. `App/PlayerView.swift:4353-4369` is the current Options order. Playlists can coexist but only the active source contributes tab visibility.
